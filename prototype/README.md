# CineShelf web prototype

این پوشه نمونهٔ قدیمی Vue/Vite را فقط برای مقایسه و آزمایش طراحی نگه می‌دارد.
برنامهٔ اصلی CineShelf از `src/cineshelf` و سیستم build مبتنی بر Meson استفاده
می‌کند؛ هیچ‌کدام از فایل‌های این پوشه در بستهٔ GNOME یا Flatpak نصب نمی‌شوند.

برای اجرای مستقل نمونهٔ وب:

```bash
cd prototype
npm install
npm run dev
```
