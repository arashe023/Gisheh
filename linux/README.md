# CineShelf 1.3.0 for Linux

این پوشه نسخهٔ کاملاً بومی CineShelf را با Python، GTK4 و libadwaita فراهم می‌کند. ساختار پنجره و ویجت‌ها در `cineshelf.ui` تعریف شده، منطق و رویدادها در `cineshelf.py` قرار دارند، ظاهر تکمیلی از `cineshelf.css` خوانده می‌شود و داده‌های نمونه در `library.json` نگهداری می‌شوند.

رابط با `Gtk.Builder` از XML بارگذاری می‌شود. سایدبار و محتوای اصلی با `AdwNavigationSplitView` و HeaderBarهای مستقل تقسیم شده‌اند؛ نام برنامه در سایدبار قرار دارد و جست‌وجو، مرتب‌سازی، ژانر و حالت نمایش داخل بدنهٔ اصلی هستند. تم، رنگ accent و حالت high contrast نیز مستقیماً از GTK و libadwaita دریافت می‌شود.

مقصد Explore در سایدبار، یک نمای کشف محتوای مستقل را در همان فضای مرکزی باز می‌کند. فیلترهای Trending، بازهٔ انتشار و ژانر در بدنهٔ Explore قرار دارند و کارت‌های چنداندازهٔ آن بدون تغییر وضعیت Library به پنل جزئیات مشترک متصل می‌شوند.

پنل جزئیات برای فیلم و محتوای اپیزودیک ساختار متفاوت دارد و شامل Hero و تریلر، امتیازها، عوامل، فصل‌ها، ویدئوها، تصاویر و پیشنهادهای مشابه است. رنگ سطح جزئیات از `posterPalette` همان عنوان ساخته می‌شود و بدون blur زنده یا پردازش سنگین با تم Adwaita ترکیب می‌شود.

## وابستگی‌های سیستمی

- Python 3.10 یا جدیدتر
- PyGObject
- Pycairo
- HTTPX
- GTK 4.12 یا جدیدتر
- libadwaita 1.9 یا جدیدتر

در توزیع‌های Arch/Parch بسته‌های زمان اجرا معمولاً این‌ها هستند:

```bash
python-gobject python-cairo python-httpx gtk4 libadwaita
```

## اجرای مستقیم

```bash
./linux/run-linux.sh
```

## نصب برای کاربر فعلی

```bash
./linux/install-local.sh
```

این دستور فایل‌های اجرایی و دادهٔ برنامه را در مسیر اختصاصی CineShelf زیر `~/.local/share` قرار می‌دهد، launcher را در `~/.local/bin` می‌سازد و برنامه را به منوی نرم‌افزارهای لینوکس اضافه می‌کند.

برای حذف نسخهٔ نصب‌شده:

```bash
./linux/uninstall-local.sh
```

اجرای برنامه به فرایند build جداگانه یا سرویس شبکه وابسته نیست.
تغییرات کاربر در `${XDG_STATE_HOME:-~/.local/state}/io.github.cineshelf.CineShelf/state.json` ذخیره می‌شوند و با حذف یا ارتقای فایل‌های اجرایی از بین نمی‌روند.

## داده‌های زندهٔ TMDB

برای دریافت عنوان‌ها، جزئیات و تصاویر واقعی، Read Access Token حساب TMDB را در متغیر محیطی زیر قرار دهید:

```bash
export TMDB_READ_TOKEN='YOUR_READ_ACCESS_TOKEN'
./linux/run-linux.sh
```

همچنین می‌توانید داخل برنامه روی **Preferences** بزنید، توکن را در پنجرهٔ **Connect to TMDB** وارد کنید و **Save and connect** را انتخاب کنید. این روش بلافاصله بارگذاری داده و تصاویر زنده را آغاز می‌کند.

برای اجرای نصب‌شده از منوی برنامه‌ها، توکن را بدون کوتیشن و در یک خط داخل این فایل قرار دهید و دسترسی آن را روی `600` بگذارید:

```text
~/.config/io.github.cineshelf.CineShelf/tmdb-read-token
```

در صورت نبود توکن یا قطع شبکه، برنامه بدون توقف از کاتالوگ نمونهٔ محلی استفاده می‌کند. داده‌ها و تصاویر زنده توسط TMDB ارائه می‌شوند؛ CineShelf مورد تأیید یا تضمین TMDB نیست.

برای کتابخانهٔ متصل به Simkl نیز عنوان، توضیحات، ژانرها، امتیاز عمومی و همهٔ تصاویر از TMDB دریافت می‌شوند. Simkl فقط وضعیت تماشا، امتیاز شخصی، پیشرفت و عضویت در فهرست‌ها را تأمین می‌کند؛ بنابراین نمایش کامل کتابخانهٔ ابری به هر دو اتصال نیاز دارد.

## اتصال حساب Simkl

در صفحهٔ **Profile** روی **Connect Simkl** بزنید. برای اولین اتصال، Client ID برنامه‌ای را که در [Simkl Developer Settings](https://simkl.com/settings/developer/) ساخته‌اید وارد کنید. CineShelf صفحهٔ تأیید را در مرورگر باز می‌کند؛ با وارد کردن PIN، کتابخانه، تصویر پروفایل و آمار واقعی حساب دریافت و در رابط نمایش داده می‌شوند.

CineShelf به Client Secret یا رمز عبور حساب دسترسی ندارد. Access Token در فایل زیر با سطح دسترسی `600` ذخیره می‌شود:

```text
~/.config/io.github.cineshelf.CineShelf/simkl-access-token
```

برای استقرار سازمانی یا اجرای موقت می‌توان Client ID و Access Token را به‌ترتیب از متغیرهای `SIMKL_CLIENT_ID` و `SIMKL_ACCESS_TOKEN` نیز تأمین کرد. با **Disconnect Simkl** توکن محلی حذف می‌شود و هیچ تغییری در حساب ابری Simkl ایجاد نخواهد شد.

### مشاهدهٔ روند همگام‌سازی

گزینهٔ **Application Log** در منوی اصلی، مراحل ورود و همگام‌سازی وضعیت Simkl، enrichment کاتالوگ TMDB، مدت هر مرحله و تعداد عنوان‌ها را به‌صورت زنده نمایش می‌دهد. همین اطلاعات در ترمینال و فایل چرخشی زیر نیز ثبت می‌شوند:

```text
~/.local/state/io.github.cineshelf.CineShelf/cineshelf.log
```

فایل لاگ حاوی PIN، Client ID یا Access Token نیست و با سطح دسترسی `600` نگه‌داری می‌شود.
